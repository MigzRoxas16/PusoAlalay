# PusoAlalay

Filipino and English heart-health journal for Android (Kotlin, Jetpack Compose). Academic thesis prototype: a personal journal, not a diagnostic or medical device.

- Package: ph.pusoalalay.app
- Android 8.0+ (minSdk 26), target SDK 35
- Records stay on the device, encrypted with Android Keystore. No internet permission.

## Getting the APK

Every push runs the "Build PusoAlalay APK" workflow (Actions tab). When it is green, download the PusoAlalay-v1.0-debug artifact, unzip it, and install PusoAlalay-v1.0-debug.apk on your phone.

Build reports and full documentation are in PusoAlalay-Android-Fixed.zip (docs folder).
